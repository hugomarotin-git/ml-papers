# ml-papers

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24093891.svg)](https://doi.org/10.5281/zenodo.24093891)

Research papers on machine-learning validation, with the code, the dated campaign outputs and
the LaTeX sources that produce every number, table and figure. One folder per paper.

| Folder | Paper | Status |
|---|---|---|
| [`paper1-backtest-power/`](paper1-backtest-power/) | *Statistical Power of Backtest Validation Pipelines: Planted-Signal Controls Against False Negatives* (H. Marotin, 2026) | preprint v1.0, November 2026, [doi:10.5281/zenodo.24093891](https://doi.org/10.5281/zenodo.24093891) |

Code is released under the MIT licence (`LICENSE`); papers and figures under CC BY 4.0.
Datasets are not redistributed: each paper folder says where they come from and how to rebuild
or download them. The `data/` directory next to the paper folders is git-ignored.
